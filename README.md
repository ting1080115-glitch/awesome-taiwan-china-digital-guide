## 1. 跨境網絡連線與出海工具 (Network & Connectivity)

海外華人與商務旅客前往中國大陸、或港澳台用戶跨區存取內地網絡時的核心連線工具與協議：

- **主流開源客戶端 (Open Source Clients)**
  - [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev) - 跨平台 Clash GUI 客戶端，支援 Windows / macOS / Linux。
  - [v2rayN](https://github.com/2dust/v2rayN) - Windows 平台老牌 GUI 客戶端，支援 V2Ray / Xray 等多核心。
  - [Sing-box](https://github.com/SagerNet/sing-box) - 通用代理平台核心，具備低延遲與高並發特性。
  - [Shadowrocket](https://apps.apple.com/app/shadowrocket/id932747118) - iOS 平台必備規則分流代理工具（小火箭）。

- **連線配置與防失聯實務**
  - 分流規則配置：建議開啟繞過大陸 IP（Bypass CN）或 GEOIP 規則，保障本地金融與即時通訊暢通。
  - 協議選擇：推薦使用 Reality、VLESS 或 Trojan 搭配 TLS 偽裝，提升跨區握手成功率。

## 2. 數位帳號與生態系指南 (Digital Accounts & App Store)

海外用戶獲取中國大陸地區專屬 App、影音串流與生活應用時的註冊與維護要點：

- **大陸 Apple ID 獲取與防鎖號**
  - [2026 大陸 Apple ID 免信用卡註冊完整指南](https://www.donaa.org/apple-id-guide-5/) - 台灣與海外用戶安全獲取中國 App Store 帳號的標準流程。
  - [大陸 Apple ID 帳號安全管理與防風控全解析](https://www.donaa.org/apple-id-guide-4/) - 避免跨區登入觸發安全鎖定、正確設置付款方式與密碼找回教學。
  - [大陸 Apple ID 手機門號驗證實務](https://www.donaa.org/apple-id-guide-3/) - +86 門號與雙重驗證解決方案。

- **影音串流跨區避坑**
  - 愛奇藝大陸版與騰訊視頻大陸版：片庫豐富度遠大於海外國際版（如 WeTV），若需追大陸獨播熱門劇集，建議優先使用大陸專屬帳號。

## 3. 大陸熱門遊戲與實名規範 (Gaming & Identity Verification)

- **雷霆遊戲與熱門手遊註冊**
  - [雷霆遊戲帳號海外註冊與實名避坑完全攻略](https://www.donaa.org/leiting-game-account-taiwan/) - 台灣用戶順暢遊玩《問道》、《一念逍遙》等雷霆旗下遊戲的帳號註冊與合規指引。
  - 實名認證新規：大陸防沉迷系統要求嚴格的二代身分證號或港澳台居民居住證驗證，海外玩家切勿使用網上無效假號，避免充值後帳號遭永久凍結。

## 4. 港澳台赴內地出行與支付 (Travel & Mobile Payment)

- **交通出行法寶**
  - [12306 鐵路官方 App](https://www.12306.cn/) - 支援台胞證與回鄉證在線核驗購票，無須取票直接刷證過閘。
  - 地鐵出行：支付寶「出行」乘車碼已全量支援內地絕大多數一二線城市地鐵與公車。

- **跨境行動支付實務**
  - 微信支付（WeChat Pay）與支付寶（Alipay）現已全面支援綁定境外信用卡（Visa / Master / JCB），200 元人民幣以下免手續費。

## 5. 亞洲周邊跨境實用好站推薦 (Helpful Regional Resources)

- [China Travel Check](https://gochina.taoliapp.com/) - 英文實測向中國大陸獨立旅行手冊：簽證/過境、支付、eSIM、火車與常用 App（每頁標註核驗日期）。
- [Kinxia 內地出行指南](https://www.kinxia.top/) - 專注港澳台赴大陸交通訂票、證件辦理與通訊開通實測。
- [JPVoy 日本自由行交通大魔王解法](https://www.jpvoy.com/) - iPhone 西瓜卡 (Suica) 綁定避坑、JR Pass 跨區選購實測指南。
